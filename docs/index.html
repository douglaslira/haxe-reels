haxe-reels

Standalone reel engine for OpenFL / Haxe. Spin, land, cascade — outcome arrives through setResult.

View on GitHub Install

Motion layer, not game math

haxe-reels owns strips, timing, pooling, pins, tumble, MultiWays reshape, and win presentation. Your RGS owns wins, wallet, and RNG.

  1. Build a ReelSet Geometry, symbols, speed profiles, optional cascade or curve.
  2. Call spin() Strips accelerate. Decorative weights fill the blur — not the payout.
  3. setResult(grid) Authoritative column targets from your server trigger the stop sequence.
  • Spin FSM Start → spin → anticipation → stop, with skip/slam and per-reel delays.
  • Cascade / tumble Fall → place → drop-in, plus refill modes combined and gravity-then-drop.
  • MultiWays & pins Reshape cell counts in a fixed reel box; sticky and walking pin overlays.
  • Hold & Win board Independent 1×1 strips in a W×H grid via HoldAndWinBuilder.
  • Headless tests FakeClock + utest — no Stage required for CI.

Install

Haxe 4.x, OpenFL, and Lime. Drop the haxelib into any Lime project.xml.

Minimal spin

Bitmap symbols, live Stage clock, land from a server grid.

Main.hx
var reelSet = new ReelSetBuilder()
  .reels(5).visibleCells(3).symbolSize(140, 140)
  .liveClock()
  .symbols(function(r) {
    r.registerClass("cherry", BitmapReelSymbol, {bitmapData: cherry});
    r.registerClass("seven", BitmapReelSymbol, {bitmapData: seven});
  })
  .weights(["cherry" => 40, "seven" => 10])
  .speed("normal", SpeedPresets.NORMAL)
  .build();

stage.addChild(reelSet.view);
reelSet.spin(onComplete);
reelSet.setResult(serverGrid); // ColumnTarget[]

Scope

Clear boundary between engine and game services.

In the engine

  • Builder, phases, StopFrameQueue land, pooling
  • Bitmap / headless / big symbols, Spine adapter hooks
  • Skip, slam, anticipation, stop stagger
  • Cascade, MultiWays, pins, WinPresenter
  • Hold & Win board, FakeClock harness

Your game / RGS

  • Paytable, ways/lines, certified RNG
  • Wallet debit before spin
  • Audio, full HUD frameworks, bonus FS machines
  • Spine runtime binding (bring your own)
